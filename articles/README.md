# Articles

One folder per article: `articles/<id>/` holds `article.md` (the article, in Markdown, with its
facts in the block at the top), `references.bib`, `data/` (the data behind every figure),
`code/` (the code that draws each one) and, where the article supplies pictures, `figures/`. A submission starts as a copy of `templates/article/`
under a working name; the editors give it its identifier when it is published.

The source here is the article as it stands. Each published version is frozen, as it was built,
under `published/<id>/`.
