# Theme

A copy of hertzforge.com's stylesheet, fonts, header and footer, taken from a build of the
website repository at the commit in `SOURCE.json`. Every article version is frozen with the
copy it was built with. Do not edit these files; refresh them with
`python3 scripts/sync-theme.py`.

The stylesheet, header and footer are under the MIT license, as the website is. The fonts
are under the SIL Open Font License 1.1; each family's license is in `fonts/`.
